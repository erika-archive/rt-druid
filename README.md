# RT-Druid — Unofficial Historical Archive

This is an unofficial historical archive of RT-Druid. It is not an official project repository and does not imply endorsement by the original authors or maintainers.

## Source and coverage

- Original SVN repository: `svn://svn.tuxfamily.org/svnroot/erika/erikae`
- Project directory: `repos/rtdruid`
- Repository UUID: `88d5ba13-baa4-4915-ae7a-41304cef7dd7`
- Source snapshot: **r3454**, retrieved on 2026-11-06.
- Imported: trunk, all 2 development branches, and all 24 named tags, including their available histories.
- Original SVN usernames, commit dates and messages are retained. A `git-svn-id` trailer links each imported commit to its original path and revision. UUID-based author addresses identify SVN accounts; they are not verified personal email addresses.

## Branches and directory layout

`main` combines this archive notice with the original trunk history. The unchanged imported trunk is available on [`svn/trunk`](https://github.com/erika-archive/rt-druid/tree/svn/trunk). Original development branch names and tag names are retained.

The original SVN directory layout is preserved. Trunk source files are under `rtdruid/`. Some original SVN tags were copied from a different directory depth; their layouts intentionally follow those originals.

Tags that were deleted and later recreated also have their earlier incarnations preserved under branches named `svn-retired/tags/<name>@r<last-revision>`.

## Preservation and verification

The migration was checked against the original SVN fulltext history: file contents, file modes, directory copies, authors, commit dates and log messages. A separate complete SVN dump retains SVN-specific properties, empty directories, exact revision metadata and copy records that Git cannot fully represent. SVN externals remain historical references; external repositories are not silently vendored into this archive.
